永磁同步電機(PMSM) 中, FOC 的位置 (θ) 估算主要可分為 Sensor/Sensorless

+ Sensor
    > 外加位置感測器
    > + 高精度的速度和位置控制
    > + 在高負載和低速工作條件下, 也能保持高效工作
    > + 能夠自動識別電機轉子的初始位置

    - 有位置感測器的電機控制演算法, 具備精確位置控制的能力,
    適用於需要高精度位置控制的場景, 如機器人運動控制, 工業自動化控制等

+ Sensorless
    > 通過各種演算法, 計算或估計電機轉子的位置
    > + 價格低, 便於生產
    > + 電路簡單, 不需要額外的位置感測器和複雜的控制演算法

    - 無位置感測器的電機控制演算法, 適用於一些價格敏感的場景, 如家電, 電動工具, 無人機等

    - Sensorless FOC 是通過估算 Motor 的位置, 來計算 FOC 所需的換相角度, 實現FOC演算法.
        > 通常 Motor 的速度和位置, 是根據測量 Motor 的電流和電壓估算出的

# Definitions

+ 磁通量 (magnetic flux, 符號 `φ`)
    > 通過某給定曲面的磁場(亦稱為磁通量密度)的大小的度量
    >> 磁通量的國際單位制單位是韋伯

    - 假設在磁感應強度為 B 的勻強磁場中, 有一個面積為 S 且與磁場方向垂直的平面,
        磁感應強度為 B 與面積S的乘積, 也叫做穿過這個平面的磁通量, 簡稱磁通(Magnetic Flux)

        ```
        當 B 與 S 平面垂直
            φ = BS

        當磁場與平面不垂直的情況下, 設 S 與 B 的垂面存在夾角θ時
            φ = B * S * cosθ
        ```

+ 磁鏈 (magnetic flux linkage, 符號 `ψ` or `λ`)
    > 是一個電磁學的物理量, 為通電線圈的匝數 N 與磁通量 φ 的乘積, 故又稱磁通匝

    ```
    ψ = N * φ
    ```

+ 氣隙 (空氣間隙, Air-Gap)
    > 指磁體或磁體接觸面之間的間隙

    - 理想情況下, 如果接觸表面平坦且乾淨, 則不考慮罐形磁鐵和接觸表面之間的氣隙
        > 事實上, 任何灰塵、碎屑、油漆、鏽跡和不那麼平坦的表面都會產生氣隙, 從而影響保持強度
        >> 當有氣隙時, 因空氣的導磁率遠低於鐵芯導磁率, 所以磁動勢會在停留在氣隙上, 增大磁阻, 使其導磁率大大下降


+ 凸極效應
    > 當氣隙不均勻, 也即直軸(d-axis)和交軸(q-axis)的有效氣隙不同時, d-q軸電樞反應電抗對電機性能的影響稱為凸極效應
    >> **凸極率**常用交軸電感Lq與直軸電感Ld的比值表示

    - 在 PMSM 中, 當 d-axis 電感與 q-axis 電感不一致時, 從電磁轉矩的方程可以看出, 輸出的轉矩多了一部分的**磁阻轉矩**
        > d軸磁鏈方向上包含永磁體, 磁導率比q軸小, 所以一般Ld小於Lq


# Sensorless

基本可分為最早的 **間接磁場導向控制(Indirect Field-Oriented Control, IFOC)** 
到現在主流 **直接磁場導向控制(Direct Field-Oriented Control, DFOC)**
>> DFOC 也稱為**回饋磁場導向控制**, IFOC 也稱為**前饋磁場導向控制**

+ IFOC 可以在從零速到高於馬達額定頻率以上的弱磁區運作, 因此較常使用
    > 在 IFOC 中會先量測定子電流及轉子速度, 再利用轉子速度及轉差率的計算值推導轉子角度, 再得到磁通的轉子角度

+ DFOC 利用電壓型或電流型的磁通模型, 計算磁通大小及轉子角度

無位置感測器的 PMSM 控制方法從估算來源可分為
> + 反電動勢 (BEMF) 位置估算
> + 定子磁鏈 (magnetic flux linkage) 位置估算
> + other

## 定子磁鏈 (magnetic flux linkage) 位置估算

利用定子磁鏈向量, 使用轉子參考系 dq 電壓方程式計算
> 其主要問題是, 由於整合過程可能會隨著時間的推移而產生偏移(可以透過使用適當的積分方法來解決這個問題), 
同時也無法檢測到初始轉子位置

+ **磁鏈觀測器**以其簡單，低速效果好而聞名
    > 龍貝格觀測器


## 反電動勢 (BEMF) 位置估算

反電動勢 (BEMF) 位置估算, 適用於中高轉速上, 在零速和低轉速時(低於 motor 額定轉速 10%), 由於 BEMF 太小, 易被雜訊干擾
> 目前主流做法, 雖存在低速下無法精確估測位置, 但可使用開環電壓控制來解決

> 基本可分為 Estimator 和 Observer
> + 開迴路的估測器 (Open-loop Estimator)
>> e.g. PLL Estimator
> + 閉迴路的觀測器 (Close-loop Observer)
>> e.g. SMO

+ Estimator

+ Observer
    > 使用 **PMSM 數學模型** 建立一個虛擬系統, 該虛擬系統用與實際系統, 有相同的相電壓激勵.
    >> 目的是讓這個虛擬模型, 產生估計輸出, 然後將其與真實電機的測量輸出進行比較.<br>
    其中虛擬量和物理量之間的誤差, 用於校正狀態觀測器的輸出, 然後狀態觀測器用於校正轉子位置

    - 由於 PMSM 模型從定義上是非線性的, 狀態觀測器的設計和實現通常非常複雜,
        但演算法通常**對參數變化和測量雜訊非常 robust**

    - Observer 方法的主要缺點, 除了計算要求高和設計複雜外, **無法檢測轉子的初始位置**



### PLL Estimator

PLL (Phase-Locked Loop, 鎖相環)是一種通過**相位誤差控制**的反饋系統, 對基準訊號與 feedback 訊號進行頻率比較,
當輸出訊號的頻率與輸入訊號的頻率相等時, 輸出電壓與輸入電壓保持固定的相位差值,
二者的相位必須相同, 且鎖住其中電壓控制振盪器和相位比較器相互連接,
使得振盪器頻率(相位), 可以精準跟蹤施加的頻率或相位調製訊號的頻率

> 優點: 相容多種電機, 適合**低轉速 Motor**

### [SMO](./note_smo.md)

滑膜觀測器(SMO)是一種在不影響電機控制性能的前提下, 將 PMSM 的數學模型簡化,
並補償數學模型後, 引入了一個修正值或者叫校正因子(Z)

通過反饋來不斷的計算 Z, 使電機數學模型無限的接近真實 Motor, 就算外部突發干擾也能通過修正值 Z 快速的修正狀態

> 如果真實系統是一條曲線, SMO 觀測器就是圍繞這條曲線來回滑動的線條, 簡單且性能較好的演算法
>> 優點: SMO 的波形更平滑好看, 適合**中高速的 Motor**

+ ASMO (自適應滑模觀測器)
    > ASMO 相對於 SMO 觀測器, 參數調整更加容易.
    ASMO 自適應滑模觀測器, 對反電動勢 Ke 參數的敏感度降低
    >> Ke 參數設定值在很大範圍內都能使 演算法 穩定運行

    - 優點: 相容性比 SMO 好, 對 Ke 反電動勢敏感度降低, **調整參數更容易**


## Other 位置估算

### 高頻注入法 (High Frequency Signal Injection)

由於凸極比高, 此類技術特別用於**凸極**或**內建磁鐵** PMSM 類型

對於 PMSM, d-axis 的磁抗低於 q-axis 的磁抗.
因此對於注入相同電壓訊號時, 在 d-axis 上測量的電流幅度, 高於在 q-axis 上測量的電流幅度.
反之亦然, d-axis 電感低於 q-axis 電感
> 這種效應是由於 d-axis 周圍的磁芯飽和引起的

基於這些觀察, 可以建立一個精確的觀察器, 來利用磁飽和的影響, 並準確估計即使在**零速度**下的速度
