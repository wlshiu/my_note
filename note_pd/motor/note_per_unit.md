Pre-unit (標么(ㄧㄠ)化) [[Back](./note_FOC.md#常用參數)]
---

將物理量的實際值, 除以一個選定的同單位的基準值, 這個過程就叫做**標么(ㄧㄠ)化**,
而 **標么(ㄧㄠ)化** 的核心是`如何選定合適的基準值`

> 經過 Pre-unit 後, 其物理量的值都限定在 `[-1, 1]`之間, 同時也便於做 **定點數Q15** 計算
>
> ```
> PU-Value (Pre-Unit) =  Real-Value / Base_Value
> ```
>> 在程式碼中經常會看到多少`pu`, 這裡的`pu`就是`Pre-unit`的縮寫 <br>
而 **么(ㄧㄠ)** 在中文就是排行最小的意思, 數字中最小的即是 1, 即 PU-Value 就是以標準`1`為基準比較的結果

+ 在數值分析中, 兩種實際數據的量級差異很大時, 很難分析其關聯性, 因此藉由正規化(Pre-Unit 為正規化的一種) 來**等效(非等於)**分析結果
    > 假設實際中的電壓 V = 310V, 電流 I = 0.3 A, 如果直接計算功率 P = UI, 就是一個很大的數乘以一個很小的數, <br>
    但如果我們定義 `電壓基準值 (V_base) = 500V`, `電流基準值 (I_base) = 1A`,
    在程式碼中計算公式, 就變成 PU-Value 的相乘, 即 `V_pu * I_pu = 0.62 * 0.3` (等效關係). <br>
    使用這種方式表示, 即使真實世界差別很大的物理量, 在程式碼世界中差別也不大

+ 做**標么(ㄧㄠ)化**時, 在模型中相同的物理量, 都必須做**標么(ㄧㄠ)化**
    > e.g. 電阻做 Pre-Unit時, 整個模型的電阻參數都必須做相同的 Pre-Unit

+ 電機 Pre-Unit **標么(ㄧㄠ)化** 有何好處

    - 簡化計算
        > 標幺化系統中的計算通常更簡單, 因為它消除了單位之間的轉換,
        使得不同額定值的電機或系統之間的比較和計算變得更直觀

        1. 可將公式的常數值, 合併到 `基準值`, 藉此節省計算的次數
            > 藉由默認 `基準值`, 在模型計算過程中, 可省略處理 `基準值`, 在最終結果再做適當處理

    - 便於比較
        > 不同容量或不同額定值的電機, 可以通過標幺值直接進行比較, 因為所有的值都被 歸一化 到統一的標準上

    - 縮放靈活性
        > 在電力系統分析中, 標幺化允許工程師輕鬆地對電機進行縮放, 以模擬不同大小的系統, 而不必重新計算所有參數

    - 模型通用性
        > 標幺化參數可以用於建立通用的電機模型, 這些模型可以應用於不同大小和類型的電機, 只需適當地選擇基準值

    - 提高直觀性
        > 由於所有參數都是**相對於基準值**的, 因此電機的運行狀況(如 負載百分比, 過載情況等)可以更直觀地表示

    - 降低複雜性
        > 在電力系統分析中, 尤其是在多機系統中, 使用標幺值可以減少分析的複雜性, 因為所有的系統元件都使用相同的參考基準

    - 故障分析
        > 在故障或其他非線性事件的分析中, 標幺系統提供了一種方便的方法來比較不同裝置的應對能力和故障電流水平

+ 電機控制中一般會對 `頻率 f(Hz)/電流 I(A)/電壓 V(V)` 做 Pre-unit
    > 這三個最基本的物理量, 可推演出電機數學模型中, 所有其他的間接物理量

    ![Elec_Physical_Quantity](./Elec_Physical_Quantity.jpg)

    - 電阻 ( R)
        > 阻抗 (Z) 包含電阻和電抗

        ```
        V = IR
        R_base = V_base / I_base
        Z_base = V_base / I_base
        ```

    - 電角頻率 (ω)

        ```
        ω = 2π * f_base
        ```

    - 電感 (L)
        > `Z_l`為電桿阻抗

        ```
        V = L * (dI(t)/dt)
        T * V(t) = L * I(t)

        L = T * V(t) / I(t)
          = T * Z_l
          = Z_l / 2π * f_base
          = Z_l / ω

        L_base = Z_base / ω_base
               = (V_base / I_base) / 2π * f_base
        ```

    - 週期

        ```
        T = 1 / freq

        圓周運動週期:
        T_base = 1 / ω_base
               = L_base / Z_base
        ```
