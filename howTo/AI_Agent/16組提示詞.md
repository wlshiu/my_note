# NotebookLM 16 組提示詞，精準提取海量數據精華


## Phase 1: 建立基礎 (Grasp)

1. `5個核心問題`
    > Reddit 稱之為**遊戲規則改變者**
    >> 強制生成堅實的教學結構

    ```
    分析所有輸入內容, 生成**5個核心問題**, 這些問題可以捕捉所有內容的主要觀點和核心意義
    ```

2. 課程和閱讀材料終極提示詞
    > 捕捉中心意義, 聚焦於定義與關係

    ```
    審查所有上船材料, 生成5個核心問題捕捉中心意義. 聚焦於**核心主題和定義**, **強調的關鍵概念**, **概念之間的關係**, **提到的實際應用**
    ```


## Phase 1: 激發好奇 (Explore)

3. `有趣數據` 提示詞

    ```
    這些資源中最令人驚訝或有趣的資訊是什麼? 包含**關鍵引用**
    ```

4. 擴展版本加引導
    > 針對特定主題的定向挖掘

    ```
    我有興趣寫關於 xxx 主題的內容. 這些資源中與 xxx 主題相關且**最令人驚訝的事實或想法**是什麼 ? 包含關鍵引用.
    聚焦 [xxx具體方面], 忽略 [yyy 方面]
    ```

## Phase 2: 轉換形式 (format)


5. 競賽格式
    > AI 扮演主持人, 故意出錯以測試您的知識深度

    ```
    兩個主持人競賽. 第一個向第二個提問 xxx 主題. 共10個問題, 混和選擇題和真假提.
    主持人有時出錯, 另一個給出正確答案糾正. 最後分享成績
    ```

6. 多語言播客的技巧
    > 製作沉浸式外語學習材料

    ```
    這是完全用 xxx 語言製作的 xxx.
    特殊指示: **全程僅用 xxx 語言**, 除了澄清獨特術語外, 不用英文.
    ```

## Phase 2: 專家視角 (Personas)

7. 產品經理角色 (google 官方)
    > 將文檔轉化為決策備忘錄, 尋找盲點

    ```
    作為審查內部文檔的**首席產品經理**. 無情的搜索可行見解, 忽略冗長文本.
    按照**決策備忘錄**格式合成: 用戶證據(直接引用), 可行性檢查(技術限制), 盲點(缺失內容).
    用專案符號.
    當我提問含糊時, 強制我澄清
    ```

8. 科學研究員角色(google 官方)
    > 優先考慮方法論, 樣本量和統計顯著性

    ```
    作為資深科學家的研究助手,
    語氣: 嚴格客觀, 正式準確.
    假設 xxx 領域高級知識, 不要定義標準術語.
    聚焦 方法, 資料完整性和矛盾.
    優先考慮樣本量, 實驗設計和統計顯著性, 非寬泛結論.
    用加粗標題分區: 主要發現, 方法優缺點, 矛盾點
    ```

## Phase 2: 翻譯與結構 (Translate)

9. 高中教師角色(google 官方)
    > 將密集內容翻譯成7年級易懂的語言

    ```
    作為充滿活力的高中教師, 將原始文檔翻譯成7年級學生能理解的語言.
    結構每個回答: 一句話總結, 列舉實際例子, 詞彙解釋.
    密集段落轉換成真假題格式
    ```

10. 文獻綜述主題提示詞
    > 找出最常見主題並以表格呈現, 適合學術研究

    ```
    從關於 xxx 主題的文章中, 找出 5~10個最常見的主題.
    對每個主題提供: 用自己語言的簡要定義, 那些章節提及它(含引用), 一句話說明它如何被處理(討論,假設, 證實).
    以結構化表格呈現
    ```

## Phase 3: 批判思維 (Critical)

11. 尋找矛盾提示詞
    > 揭示資源間的分歧與衝突原因.

    ```
    從關於 xxx 主題的文章中, 找出**重要矛盾或衝突發現**.
    對每個矛盾提供: 各方具體說法(引用), 分歧的可能原因(方法, 樣本, 背景), 什麼證據能解決衝突
    ```

12. 基於資源的間隙分析 (Gap Analysis)
    > 將**你的嘗試**與**理論資料**比對, 找出漏掉的步驟

    ```
    分析此嘗試與我上傳材料的關係: 項目'我嘗試的', 我的方法'我遵循的步驟', 結果'發生了什麼', 預期'應該發生什麼'.
    交叉引用資源: 引用我未遵循的方法, 識別我完全遺漏的概念, 找出我跳過的先決條件
    ```

## Phase 4:  連結與行為 (Synthesize)

13. 實施概念提示詞
    > 將研究轉化為明確的行動步驟

    ```
    幫我實施 xxx 主題的概念.
    對每個相關資源: 引用關鍵證據, 與其他資訊關聯, 指出衝突觀點, 提供**明確行動**
    ```


14. 綜合概念提示詞
    > 尋找不同主題間抽象的連接與有趣的組合.

    ```
    綜合 xxx 主題與 yyy 主題之間的連接, 無論多抽象.
    對每個相關資源: 引用關鍵證據, 與其他資訊關聯, 指出衝突觀點, 提出有趣的組合
    綜合為清晰總結, 聚焦連接, 基於引用, 承認缺口
    ```

## Phase 4: 深度深潛 (Deep Dive)

15. 主題綜合分析
    > 生成準確, 充分論證的長篇資訊, 分離事實與解釋

    ```
    提供關於 xxx 主題的準確, 充分論證的資訊.
    計畫探索必要方面, 關鍵問題與爭議.
    結構包括: **概覽** (總結與概念), **分析** (證據與限制), **資源**(衝突與信心水準).
    規範: 分離事實與解釋, 用證據維持主張, 保持客觀性
    ```

16. 辯論格式提示詞
    > 讓兩個主持人, 針對同一個主題進行相反立場的辯論.

    ```
    生成兩個主持人就 xxx 主題, 進行相反立場的辯論.
    主持人A 支持 立場A, 主持人B 支持 立場B.
    他們應質疑彼此的論點, 引用資源中的具體證據, 讓聽眾決定誰提出了最有力的案例
    ```
